# Job search criteria

Describe what you're looking for. The workflow uses this to build search queries and filter results.

## Roles and focus

- **Roles:** e.g. Software Engineer with focus on cybersecurity, red team, blue team, security engineering
- **Keywords to include:** security engineer, application security, penetration testing, incident response, SOC
- **Keywords to exclude:** (optional) e.g. senior only, management only

## Experience level

- **Target levels:** entry, intern, junior, mid-level (list what you want)
- **Employment types:** full-time, part-time, contract, internship

## Location and remote

- **Locations:** city, state, or "remote", "hybrid"
- **Remote preference:** remote only, hybrid ok, or on-site ok

## Other

- **Companies or industries:** (optional) specific companies or sectors
- **Date posted:** e.g. last 7 days, last 2 weeks

---

Example summary for the agent:

I'm looking for software engineer roles with an emphasis on cybersecurity: red team, blue team, security engineering, application security. Experience levels: entry, intern, junior. Prefer remote or hybrid. Full-time or contract. Postings from the last 2 weeks.
